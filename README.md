# Hypothesis Validator — by Xavi Marín

Part of the [PO Toolkit](https://xavimarin.net) · Tool #9 of 9

Define A/B test hypotheses, enter your results, and get statistical significance calculated automatically using chi-square test — all in the browser, no backend needed.

## Setup

```bash
npm install
npm run dev
```

No API keys required. All statistics run client-side.

## Deploy to Vercel

```bash
npx vercel deploy
```

## Tech stack

Next.js 14 · TypeScript · Tailwind CSS · Chi-square statistics in JS · Vercel
